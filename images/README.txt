PUT YOUR TWO IMAGE FILES IN THIS FOLDER
=======================================

The website expects exactly these two files, named exactly like this
(lowercase, same spelling):

  1. logo.png    <-- the campaign logo  (currently at i.postimg.cc/vTjk0Qk4/Logo1.png)
  2. dilks.jpg   <-- the photo of Michael (currently at i.postimg.cc/YqPMP7Y1/DILKS1.jpg)

How to get them:
  - Open each link above in your browser, right-click the image, "Save image as..."
  - Rename them to logo.png and dilks.jpg
  - Drop both into this /images/ folder before (or while) uploading to GitHub

Until both files are here, the logo and photo will show as broken images.
Everything else on the site will still work.

You can delete this README file once the two images are in place.
